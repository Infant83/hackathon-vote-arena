1. 행사 흐름

화면별 역할을 먼저 잡습니다

Vibe Arena는 여러 행사 조합을 한 콘솔로 운영하는 앱입니다. 해커톤의 투표와 응원, 분기 모임의 Q&A와 퀴즈, 특별 세션의 혼합 운영을 같은 순서로 다룹니다.

/message

참가자 Q&A

별명으로 입장해 질문을 남깁니다. 퀴즈가 열리면 참가자 화면은 퀴즈 답변 화면으로 전환됩니다.

/vote

투표와 응원

해커톤 행사에서 팀별 별 배분, 응원 메시지, 행운권 응모 조건을 처리합니다.

/wall

발표장 송출

Q&A, 퀴즈, 실시간 현황, Showup, 추첨을 행사 조합에 맞춰 보여줍니다.

/admin

운영 콘솔

설정, 콘텐츠, 미리보기, 내보내기, 초기화, 점검 기준을 계속 확인하는 운영자의 자리입니다.

2. DB room 안전 규칙

행사 DB는 ARENA_ROOM_NAME으로 분리됩니다

관리자 preset은 현재 room의 설정을 갱신합니다. 질문, 참가자, 퀴즈, 응원, 당첨 이력이 저장되는 DB room은 배포할 때 지정한 ARENA_ROOM_NAME이 결정합니다.

행사 slug를 정합니다

hackathon26q1, meeting26q1, special26ax처럼 짧고 나중에 찾기 쉬운 이름을 씁니다.

Worker name과 room을 맞춥니다

권장 규칙은 Worker name = ARENA_ROOM_NAME = event.roomName입니다.

Preset은 현재 room 설정을 갱신합니다

관리자 화면에서 settings를 불러오면 현재 room의 설정이 갱신됩니다. room 전환은 배포 단계에서 처리합니다.

Reset 전에는 room과 export를 확인합니다

초기화 대상은 현재 Worker가 보는 현재 room입니다. 먼저 JSON, XLSX, settings를 저장합니다.

3. 관리자 콘솔

운영 콘솔에서 먼저 볼 것

기본 /admin 화면은 운영 판단을 위한 콘솔입니다. 별 현황이나 메시지 본문은 상세 패널 또는 /wall에서 보고, 기본 화면에서는 현재 행사와 관리 작업을 확인합니다.

운영 대상

현재 운영 대상

Worker, 현재 DB room, settings 권장 room, 내보내기와 초기화 경계를 먼저 봅니다.

운영 콘텐츠

저장 전 미리보기

화면별 문구와 팀 사진은 저장 전 미리보기로 실제 노출 형태를 확인합니다.

결과 내보내기

JSON, XLSX, settings

행사 종료 백업의 기준은 JSON, XLSX, settings 세 파일입니다. Reset 전에도 같은 순서입니다.

초기화

범위를 좁혀 실행

질문, 퀴즈 이력, 행운권, 전체 초기화를 구분하고 행사 중에는 필요한 범위만 실행합니다.

4. 배포와 점검

기본 배포와 행사별 분리 배포

현재 기본 배포는 meeting Worker와 2026-ax-q2-meeting room입니다.

현재 운영 Worker로 배포 
npm run lint
npm run build
npm run cf:deploy:dry-run
npm run cf:deploy

$env:AUDIT_URL = 'https://meeting.axgroup.workers.dev'
$env:ADMIN_PASSCODE = '<운영 passcode>'
npm run ops:audit:ax-q2
새 행사 Worker로 분리 배포 
npm run ops:audit:all
npm run lint
npm run build

npx wrangler deploy --name <event-slug> --var ARENA_ROOM_NAME:<event-slug>
5. 문제 상황 대응

운영 중 문제가 생기면 이렇게 대응합니다

행사 중 1차 대응 순서는 health 확인, 배포 이력 확인, rollback, 운영 점검입니다.

사이트 접속 오류

/api/health로 runtime과 passcode 설정을 확인합니다.

wrangler deployments list로 최근 배포를 보고, 필요하면 안정 버전으로 되돌립니다.

로그인 오류

wrangler secret list로 secret 존재를 봅니다.

wrangler secret put ADMIN_PASSCODE로 재설정하고 다시 로그인합니다.

데이터 공백

Worker name, ARENA_ROOM_NAME, settings 권장 room을 비교합니다.

현재 Worker가 보는 room을 확정한 뒤 초기화 여부를 판단합니다.

송출이 버벅임

운영에 필요한 /admin, /wall, /message 탭만 남깁니다.

운영 점검 스크립트로 SSE 탭 수, payload 크기, inline media 크기를 확인합니다.

되돌리기 명령 
npx wrangler deployments list --name meeting
npx wrangler deployments status --name meeting
npx wrangler rollback --name meeting <version_id> --message "Rollback to stable event build" --yes
6. 마감과 백업

행사 마감은 export 완료가 기준입니다

Durable Object는 현장 운영 상태를 담는 저장소입니다. 장기 보관은 종료 직후 저장한 원본과 결과표가 맡습니다.

원본 JSON 백업

/admin?panel=export에서 현재 room의 원본 운영 데이터를 내려받습니다.

XLSX 결과 저장

참여자, 메시지, 퀴즈, 당첨 이력을 사람이 읽기 쉬운 표로 보관합니다.

settings 저장

다음 행사의 출발점이 될 화면 문구, 팀 정보, 퀴즈, 운영 설정을 함께 저장합니다.

익명화 후 재사용

공개 repo나 public/prev_settings에 넣기 전 실명, 소속, 사진, 민감 상품 정보를 제거합니다.
