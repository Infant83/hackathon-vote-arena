Vibe Arena 운영 가이드 제작 노트

운영 배포에서 바로 여는 가이드는 public/help/index.html이며, 관리자 콘솔에서는 /help 링크로 연결됩니다.

Remotion 소개 덱은 app_introduction/remotion-deck에 있습니다. 이 덱은 앱 구조, DB room 규칙, 관리자 콘솔, 배포, 운영 점검, 장애 대응, 종료 백업을 단계별로 설명합니다.

  • cd app_introduction/remotion-deck
  • npm install
  • npm run dev
  • npm run still
  • npm run render

정적 가이드를 수정할 때는 Remotion 덱의 deckData.ts와 deck.config.json도 같은 운영 기준으로 맞춥니다.
