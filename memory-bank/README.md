# Vibe Arena Memory Bank

이 폴더는 다음 세션에서 작업을 이어가기 위한 로컬 운영 기억장소입니다.

- `active-context.md`: 현재 운영 기준, 최근 검증, 다음 작업에서 먼저 확인할 사항

원칙:

1. 실제 운영 데이터나 개인정보는 여기에 넣지 않습니다.
2. DB room, settings, export, reset처럼 운영 사고로 이어질 수 있는 결정은 날짜와 함께 남깁니다.
3. README/AGENTS/CHANGELOG와 내용이 어긋나면 README와 AGENTS를 기준으로 고치고, 이 파일은 요약만 유지합니다.
